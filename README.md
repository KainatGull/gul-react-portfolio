# Kainat Gul — React Portfolio

A motion-driven, responsive portfolio built with React, Vite, and CSS.

## Live Website

https://kainatgull.github.io/gul-react-portfolio/

## Run Locally

1. Install Node.js.
2. Open this project folder in your terminal.
3. Run `npm install`.
4. Run `npm run dev`.

## Build

- `npm run build`
- `npm run preview`

## Customize

- Personal details: `src/data/personalInfo.js`
- Projects and URLs: `src/data/projects.js`
- Technologies: `src/data/skills.js`
- Theme colors: `src/styles/variables.css`

## EmailJS

Configure your EmailJS service and template using the environment variables listed in `.env.example`. Copy that file to `.env`, fill in your credentials, and restart the development server.
